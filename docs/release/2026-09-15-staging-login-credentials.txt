DEMO DATA RESET
--------------------------------------------------
Running the following command on staging restores the documented
demonstration credentials and prepared presentation records:

php artisan db:seed --force

After reseeding, clear and rebuild the Laravel caches if required:

php artisan optimize:clear
php artisan optimize
