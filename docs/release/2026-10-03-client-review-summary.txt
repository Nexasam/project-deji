6. INDICATIVE MONTHLY RUNNING COSTS
-----------------------------------

These are practical MVP operating-cost estimates. Final figures depend on
traffic, number of properties, image/video volume, email volume, backups and
whether the platform remains on shared hosting or moves to a VPS/cloud server.

Recommended MVP cost posture:

- Keep application hosting simple at the beginning.
- Use object storage for property images and documents instead of keeping all
  uploads only on the web server.
- Use transactional email for booking confirmations, password resets, review
  notifications and operational alerts.
- Add SMS/WhatsApp later only for high-value alerts because message costs can
  grow quickly.

Core monthly cost buckets:

1. Application hosting

- Current shared hosting can continue for staging/demo if stable.
- For production MVP, a VPS/cloud server is safer for queue workers, cron,
  logs and deployment control.
- Estimated MVP range: $10 - $40/month for a small VPS.
- Higher-availability production setup can move above this later.

2. Database

- If using the same VPS/shared host database, there may be no separate database
  line item at MVP stage.
- Managed database is preferred later for backups, uptime and easier recovery.
- Estimated MVP range:
  - Included/self-managed: $0 extra.
  - Managed database: roughly $15 - $60+/month depending on provider and size.

3. File/media storage

Option A: DigitalOcean Spaces

- Good for property images, documents, verification files and generated media.
- Simple predictable MVP option.
- Current public pricing is about $5/month base for one Space, with included
  storage/bandwidth limits and extra usage billed separately.
- Estimated MVP range: $5 - $20/month initially.

Option B: Cloudinary

- Better if the team wants image resizing, optimisation, transformations,
  thumbnails and CDN delivery handled automatically.
- Useful for marketplace images because it can optimise images for mobile.
- Estimated MVP range:
  - Free/low tier for testing if usage is small.
  - Paid plans can become significantly higher as usage/media grows.
- Recommended approach:
  - Start with DigitalOcean Spaces for raw storage.
  - Consider Cloudinary when image optimisation and transformation become a
    clear product need.

4. Transactional email

Emails needed:

- Account verification.
- Password reset.
- Booking confirmation.
- Payment confirmation.
- Owner booking notification.
- Review submitted/moderation notification.
- Dispute updates.
- iCal/stale-sync alerts.
- Operations/task reminders.

Option A: Amazon SES

- Usually very cheap at scale.
- Requires more setup: domain verification, DNS records, SPF/DKIM/DMARC,
  sandbox-to-production approval, bounce/complaint handling.
- Estimated MVP range: usually low, often under $5 - $20/month for modest
  transactional volume.

Option B: Resend/Postmark/Mailgun-style provider

- Easier developer experience and cleaner dashboards.
- Usually more expensive than SES but faster to operate.
- Estimated MVP range: $0 - $35+/month depending on provider and email volume.

Recommended MVP approach:

- Use Resend/Postmark-style provider if the team wants faster setup and easier
  debugging.
- Use Amazon SES if the priority is lowest long-term sending cost.

5. Domain and DNS

- Domain cost depends on registrar and TLD.
- Estimated range: $10 - $30/year for common domains.
- DNS is often free through registrar/Cloudflare.

6. Backups

- Database backup.
- Uploaded media backup.
- Application release backup.
- Estimated MVP range:
  - Manual/basic: $0 - $10/month.
  - Automated offsite backups: $5 - $30+/month.

7. Monitoring and error tracking

- Useful before public launch.
- Examples: uptime monitor, error logs, application exceptions.
- Estimated MVP range:
  - Free/low tier initially.
  - $10 - $30+/month once usage grows.

8. Payment gateway costs

- Paystack/Flutterwave usually charge per successful transaction.
- This is not a fixed monthly hosting cost.
- It should be treated as a transaction cost and built into the platform fee
  model.
- The platform still needs final decision on whether guest pays the platform
  fee separately or the property owner absorbs it.

9. SMS / WhatsApp notifications

- Not required for MVP if email and in-app notifications are acceptable.
- Recommended for later:
  - check-in reminders,
  - payment alerts,
  - urgent owner/staff alerts,
  - guest support escalation.
- Estimated cost depends heavily on provider, country and volume.

Simple MVP monthly budget expectation:

- Lean staging/demo: $5 - $25/month extra beyond existing hosting.
- Practical production MVP: $40 - $150/month excluding payment transaction fees.
- More robust production setup with managed database, media optimisation,
  monitoring and higher email volume: $150 - $400+/month.

Recommended starting stack:

- Hosting: VPS/cloud server when leaving shared hosting.
- Storage: DigitalOcean Spaces initially.
- Email: Resend/Postmark for fastest setup, or Amazon SES for lowest long-term
  cost.
- Media optimisation: add Cloudinary later if marketplace image performance
  becomes a priority.
- Backups: automated database + uploads backup from the beginning of production.
